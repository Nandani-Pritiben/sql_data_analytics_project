# sql-data-analytics-project

A comprehensive collection of SQL scripts for data exploration, analytics, and reporting. These scripts cover various analyses such as database exploration, measures and metrics, time-based trends, cumulative analytics, segmentation, and more.

This repository contains SQL queries designed to help data analysts and BI professionals quickly explore, segment, and analyze data within a relational database. Each script focuses on a specific analytical theme and demonstrates best practices for writing clean, readable SQL.

---

## 📂 What's Inside

- **Database Exploration** — Scripts to understand table structure, relationships, and data distribution
- **Measures & Metrics** — Core business metrics (totals, averages, counts) across key dimensions
- **Time-Based Trends** — Analyzing how metrics change over time (monthly, yearly trends)
- **Cumulative Analytics** — Running totals and moving averages for trend analysis
- **Segmentation** — Grouping customers/products into meaningful segments for targeted analysis

---

## 🛠️ Tools Used

- **SQL Server** — Querying and analyzing the dataset
- **SQL Server Management Studio (SSMS)** — Writing and running queries
- **Git & GitHub** — Version control and project hosting
